# Final Hallucination Guardrail Report

Live evidence: `artifacts/testing/ollama_guardrail_results.json`
(15 required cases, regenerated by `scripts/test_offline.sh`), plus the

## Architecture guarantee

The score and tier are computed and persisted **before** any narrator call;
the narrator receives only verified structured facts and its output is
machine-validated. There is no code path by which the LLM can change a score,
tier, threshold, action, or piece of evidence — a rejected narration merely
swaps prose to the deterministic template.

## Fallback contract (verified)

Deterministic template produces the **same score, same tier, same reason
list**, required limitations, no LLM dependency — and itself passes the
validator. The scoring endpoint (`/v1/score`) never calls the narrator at all;
`scripts/test_offline.sh` runs the guardrail suite with the narrator pointed
at a dead port.

## Measured latency note

On this CPU, `llama3.2:3b` narration takes ~48 s (including model load);
timeout is 120 s with 1 retry. Narration is an explicit analyst action
(report generation), never in the scoring path.

**Verdict: PASS — Ollama cannot alter score/tier/action/evidence, and the
system is fully functional with Ollama stopped.**
