## The leakage story (what the firewall caught)

1. **F3912** — |corr| 0.969, single-feature *cross-validated* PR-AUC 0.943,
   balanced label reconstruction 0.988. Including it inflates LightGBM from
   0.614 to 0.942 OOF PR-AUC.
2. **F2230** — snapshot month: *every* negative is the 2025-10 snapshot,
   *every* positive is Sep/Nov/Dec. Time ≡ label; also invalidates any
   out-of-time split on this file (recorded NOT_VALID in
   `artifacts/metrics/temporal_stress_metrics.json` instead of faking one).
3. **Row order** — the file is physically sorted by label; the unnamed index
   is a perfect predictor and is quarantined.

**Verdict: PASS — no target/leak/index feature reaches any accepted model,
and every claim above is re-checkable by running `bash scripts/test_ml.sh`.**
